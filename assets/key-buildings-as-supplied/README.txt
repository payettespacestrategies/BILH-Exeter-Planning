The campus level drawings exactly as supplied, before restyling.

assets/key-buildings/ holds the versions the dashboard renders: the dashed
lines were recoloured to a light grey ghost and the solid outlines thickened,
so that at campus scale you can tell which buildings are on the level and
which are only shown for context. Nothing geometric was changed.

Note that LEVEL 3.svg and LEVEL 4.svg are byte-identical in the supplied set.
